# ASSETS & VISUAL IDENTITY PROVENANCE
## HEROES OF CODE — GFG STUDENT CHAPTER × BENNETT UNIVERSITY

### 1. Vector & Canvas Artwork Treatment
All character compositions across the application are custom-crafted procedural SVG and Canvas vector blueprints, specifically designed to adhere to legal and non-infringing design principles:
- **No Copyrighted Movie Stills or Official Promotional Posters**: No copyrighted photography or comic-book raster scans are used anywhere in this repository.
- **Monochrome Architectural Treatment**: The characters (Iron Man / Mark-LXXXV, Spider-Man / Arachnid Web, Thor / High-Voltage Mjolnir, Hulk / Monolithic Gamma, Captain America / Vibranium Sentinel Shield) are rendered using monochrome architectural blueprint geometry, etched line hatches, concentric HUD targeting rings, and low-opacity depth layers (12%–18% opacity).
- **Metaphorical Archetypes**: The characters represent core technological pillars:
  - *Iron Man*: Innovation, System Architecture & Autonomous Protocols
  - *Spider-Man*: Agility, Distributed Networks & Dynamic Client Interfaces
  - *Thor*: Raw Silicon Acceleration, High-Performance Computing & Deep Neural Nets
  - *Hulk*: High-Throughput Monolith, Big Data & Fault-Tolerant Infrastructure
  - *Captain America*: Engineering Leadership, Cadence & Mission Milestone Delivery

### 2. Particle & Mesh Systems
- **Mesh Flow (`src/components/MeshFlow.tsx`)**: Lightweight procedural 2D Canvas grid that calculates real-time gravitational mouse distortion with spring physics and dampening. Zero external image assets.
- **Particle Field (`src/components/ParticleField.tsx`)**: Procedurally generated bioluminescent Canvas particles with subtle sinusoidal opacity pulsation and continuous edge wrapping.
- **Registration Portal (`src/components/RegistrationPortal.tsx`)**: Interactive rotational particle vortex that accelerates and converges inward upon click trigger.
